CINEVERSE
A Tamil movie ticket booking website built using HTML, CSS and JavaScript

 Features
- Browse Tamil movies
- Search and filter movies by genre
- View movie posters
- Select movie showtimes
- Interactive seat selection
- Dynamic booking summary
- Demo booking confirmation

Technologies Used
- HTML5
- CSS3
- JavaScript

About
CINEVERSE is a frontend movie ticket booking prototype created to demonstrate DOM manipulation, event handling, dynamic rendering and interactive UI design.

{ This is a frontend-only demo. It does not process real bookings or payments. }
